# @atlas-eids/react

Atlas EIDS React 组件包，包含 66 个企业与 AI UI 组件及 `AtlasProvider`。其中 9 个企业组合组件统一应用框架、页面标题、数据网格、对象单元格、状态和行操作；21 个 AI 组件覆盖 Living Orb、会话、消息、流式输出、Composer、Artifact、结构化输入、Provenance、GenUI、MCP、知识源、跨页面 Agent 和工具调用。

```tsx
import { AtlasButton, AtlasOrb } from '@atlas-eids/react'
import '@atlas-eids/react/styles.css'
```

状态：Beta。
