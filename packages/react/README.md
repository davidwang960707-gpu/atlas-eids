# @atlas-eids/react

Atlas EIDS React 组件包，包含 50 个企业与 AI UI 组件及 `AtlasProvider`。其中 7 个企业组合组件统一页面标题、数据表、对象单元格、状态和行操作；15 个 AI 组件覆盖 Living Orb、会话、消息、流式输出、Composer、Prompt、附件、历史、反馈、MCP、知识源、引用、检索轨迹和工具调用。

```tsx
import { AtlasButton, AtlasOrb } from '@atlas-eids/react'
import '@atlas-eids/react/styles.css'
```

状态：Beta。
