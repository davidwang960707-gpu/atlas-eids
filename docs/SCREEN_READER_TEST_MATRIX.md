# 人工读屏测试矩阵

自动化 Axe、DOM 语义检查和键盘测试只能证明页面具备读屏基础，不能代替真实听觉顺序、上下文连续性和操作效率判断。本矩阵用于每个 Beta/RC 发布前的人工签字；没有完成实际设备测试时，人工状态必须保持 `待验证`，不得由自动化标记为通过。

## 基线环境

| 平台 | 浏览器 | 读屏器 | 人工状态 |
| --- | --- | --- | --- |
| macOS | Safari 最新稳定版 | VoiceOver | 待验证 |
| Windows 11 | Chrome 最新稳定版 | NVDA 最新稳定版 | 待验证 |

## 签字规则

测试人记录版本、系统、浏览器、读屏器版本、失败步骤和录屏/Issue 链接。任一 P0/P1 问题未关闭时不得将 Release 标记为 Stable；Beta 可发布，但 Release Notes 必须列出已知无障碍限制。
