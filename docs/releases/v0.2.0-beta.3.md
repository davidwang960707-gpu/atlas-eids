# Atlas EIDS v0.2.0-beta.3

`beta.3` 将 Atlas EIDS 从视觉与组件展示继续推进到可生成、可验证、可治理的 AI 原生企业应用工程平台。

## 本次重点

- Design Tokens 迁移到 DTCG 2025.10，形成 Global、Semantic、Component、State 四层事实源，并生成 Figma Variables 交接资产。
- 26 个页面 Recipe 补齐主任务、主操作、状态、响应式、信息优先级和完成标准。
- Validator 从正则检查升级为 AST、Type、DOM、Playwright 与视觉评测组合验证。
- React/Vue 共享 Headless 行为契约，Form、DataGrid、Combobox、Tree、Upload、DateRange、Drawer/Dialog、Menu、Notification、App Layout 进入深交互基线。
- 新增 AI Artifact Renderer、结构化输入、AI Provenance、GenUI/A2UI、MCP 工具面板和跨页面 Agent 双端组件。
- 建立 API 兼容报告、包体预算、覆盖率、三浏览器、A11y、视觉回归和人工读屏准备度门槛。
- 交付 Figma Variables、67 项组件映射、组件库规范与 React/Vue 知识库真实采用案例。

## 验证结果

- `npm run check`：构建、14 个 package 测试、67 项 API 契约、26 个 Recipe、包体、覆盖率、Figma、Skills 与 Java 均通过。
- Storybook：133 项 React/Vue 组件、行为一致性和 Axe 检查通过。
- 页面 E2E：58 项通过；A11y：24 项通过；视觉回归：16 项通过。
- Chromium、Firefox、WebKit：6 项核心流程通过。
- Java 21 + Testcontainers：14 项通过，覆盖 Keycloak OIDC、PostgreSQL 17、Flyway、RBAC 与租户隔离。
- 全新目录：14 个 tarball 安装、React/Vue CLI 项目生产构建和生成 Java Client/后端测试通过。
- 生产依赖审计：0 个已知漏洞；敏感凭证扫描未发现生产 Token、私钥或核心数据。

## 发布边界

- npm Registry 首次发布仍需 npm 侧创建或授权 `@atlas-eids` scope，并绑定 GitHub Trusted Publishing；Registry 可见前继续使用 Clone + CLI `--local`。
- Figma Variables、Library 与 Code Connect 仓库交接资产已经生成；真实 Team Library 发布需要目标文件编辑席位和可发布计划。
- Axe、键盘与语义自动化已通过；VoiceOver 和 NVDA 人工测试仍需按读屏矩阵由真实测试人签字。
- WebMCP、公网 MCP、生产 RAG Adapter 与插件市场服务仍保持 Experimental。
