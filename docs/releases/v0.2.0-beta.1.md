# Atlas EIDS v0.2.0-beta.1

这是 Atlas EIDS 的首个 Beta 版本，目标是把视觉概念、双框架组件、企业页面模板、CLI、AI Runtime、插件机制与 Java 企业集成收敛为一条可以验证的开发者链路。

## 本次重点

- React / Vue 各提供 31 个企业核心组件与 Provider，支持浅色/深色主题、中英文和三种密度。
- 提供 15 个独立运行页面模板、126 个 Pattern Lab 模式入口，以及 React / Vue Storybook。
- CLI 支持 React / Vue、7 种应用框架、15 类页面模板、3 种密度、2 种语言和第三方 Adapter。
- 提供 Ant Design React、TDesign Vue Next、OpenTiny Vue 的 Design Token 与运行时适配层。
- AI Runtime 支持会话、附件、引用、预算、成本、失败恢复、人工审批和运行追踪。
- Plugin SDK 支持 Worker / iframe 沙箱、Manifest 签名、插件索引与调用约束。
- Web Agent 支持 WebMCP 能力探测、跨页面任务、审批暂停与服务端审计回放。
- Java 21 / Spring Boot 企业后端支持 PostgreSQL、Flyway、Keycloak OIDC、RBAC、多租户和审计。
- 工程链路包含 Changesets、CI、GitHub Pages、A11y、E2E、视觉回归和发布包预检。

## 验证结果

- `npm run check`：通过。
- Playwright 浏览器回归：82 项通过，覆盖桌面与移动端。
- Storybook 交互检查：React / Vue 共 8 项通过。
- A11y 检查：22 项通过，无严重或致命问题。
- Java 单元测试：12 项通过。
- CLI：从空目录生成 React / Vue 项目并完成生产构建。
- `npm audit --omit=dev --audit-level=high`：未发现漏洞。

## 获取方式

当前版本先通过 GitHub Prerelease 提供各 Workspace Package 的 npm tarball，尚未发布至 npm Registry。需要 Registry 安装的团队请等待后续 Beta，或 Clone 仓库后使用 CLI 的 `--local` 模式。

```bash
git clone https://github.com/davidwang960707-gpu/atlas-eids.git
cd atlas-eids
npm install
npm run atlas -- create atlas-workspace --framework react --framework-layout tenant --adapter antd --backend java --local
```

## Beta 边界

- WebMCP、第三方高级控件与插件市场服务仍为 Experimental。
- Keycloak / PostgreSQL Testcontainers 集成测试依赖可访问的容器镜像仓库。
- npm Registry 正式发布、升级兼容策略和稳定 API 承诺将在后续 Beta 中继续收口。
