# Atlas EIDS v0.2.0-beta.2

`beta.2` 聚焦视觉标准收口、组件实验环境产品化与测试基础设施稳定性，让官网、React、Vue、页面模板和 Storybook 共享同一套企业级设计语言。

## 本次重点

- 统一官网、React、Vue 与双端 Storybook 的 Orb AI Core：补齐呼吸、液态形变、金属深度、碰撞高光和动态轨道。
- 明确 Orb 的 AI / Agent 语义边界，普通任务列表回归业务图标和状态表达。
- 修复 AI 审计治理页版本标签在桌面与移动端的溢出和变形。
- React / Vue Storybook 增加 Atlas 品牌主题、Controls、统一默认状态和 AI Composer 交互。
- React / Vue 各 31 个组件 Story 全量接入 Axe 严重级可访问性检查。
- Playwright 使用独立严格端口，杜绝本地其他服务导致的串站与假通过。
- 15 个独立页面模板增加桌面、移动、布局溢出和关键业务流回归。

## 验证结果

- `npm run check`：通过，包含 packages、examples、Storybook 与 Java 21 构建测试。
- Storybook 组件、交互与 A11y：72 项通过。
- E2E、A11y 与视觉回归：84 项通过，覆盖桌面和移动端。
- Java 单元测试：12 项通过。
- 变更文件敏感凭证扫描与 `git diff --check`：通过。

## 获取方式

GitHub Prerelease 提供源码与 12 个 Workspace Package 的 npm tarball。npm Registry 发布状态以 [Packages 发布状态](../PACKAGE_STATUS.md) 为准；Registry 包可见前继续使用 CLI `--local` 模式。

```bash
git clone https://github.com/davidwang960707-gpu/atlas-eids.git
cd atlas-eids
npm ci
npm run atlas -- create atlas-workspace --framework react --framework-layout tenant --adapter antd --backend java --local
```

## Beta 边界

- WebMCP、第三方高级控件与插件市场服务仍为 Experimental。
- npm Registry 首次发布需要 npm Scope 所有权与 GitHub Trusted Publishing 或 `NPM_TOKEN`。
- 生成式应用框架将在后续 Beta 继续增强真实路由、权限策略、租户会话和 Java API 契约。
