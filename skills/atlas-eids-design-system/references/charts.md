# Atlas 数据可视化规则

图表用于比较、判断和追踪，不用于展示装饰性色彩。优先使用项目已有图表库；本规则约束数据语义、Tokens 和页面组合。

## 色彩角色

| Token | 用途 |
| --- | --- |
| `--chart-primary` | 主要序列、当前对象、核心趋势 |
| `--chart-secondary` | 主要对比序列 |
| `--chart-teal` | 补充对比或稳定状态 |
| `--chart-mint` | 低强度正向状态 |
| `--chart-amber` | 警告、阈值、待处理 |
| `--chart-rose` | 异常、风险、负向状态 |

同一图表默认不超过 4 个强调色。分类超过 6 项时优先排序、分组、小倍图或交互筛选，不用更多彩虹色解决。

## 图表选择

| 任务 | 推荐 | 避免 |
| --- | --- | --- |
| 时间趋势 | 折线图、面积图 | 3D 柱状图 |
| 数量比较 | 水平条形图、分组柱状图 | 透视效果 |
| 构成占比 | 100% 堆叠条、环形图 | 超过 5 类的饼图 |
| 分布 | 直方图、箱线图 | 无尺度气泡 |
| 相关关系 | 散点图 | 双轴误导 |
| 多指标对比 | 指标矩阵、小倍图 | 过密雷达图 |
| 实时状态 | 指标、趋势、告警列表 | 持续闪烁 |

## 布局和表达

- 面积图底部保留轴标签和至少 `16px` 视觉缓冲，填充区域不能贴住容器边缘。
- SVG 设置稳定 `viewBox` 与 `preserveAspectRatio`；数据点在任何容器中保持正圆，不能被拉成椭圆。
- 图例、筛选和导出操作与图表对齐，不覆盖绘图区。
- 图表容器使用低圆角、弱边框，不使用发光边框和厚重阴影。
- 每个图表提供标题、时间范围、单位、更新时间；Tooltip 同时展示维度、数值、单位和比较基准。
- 颜色不能是唯一编码；状态同时使用文字、线型、图例或标记。风险线、目标线和预测区间必须明确区分。
- 移动端优先减少序列、改用摘要或允许受控横向滚动，不把图表压缩到不可读。

## AI 分析页

AI 生成图表必须保留用户问题、授权数据范围、图表与文字结论、可下钻明细或引用，以及不确定性和人工确认入口。图表本身不使用 Orb；Orb 只放在 AI 提问入口、Agent 身份或运行状态附近。

## 验收

- 使用图表语义 Tokens，没有无依据硬编码渐变。
- 浅色、深色主题的文字、网格和序列均满足对比度。
- 标签无截断或重叠，空数据、Loading、Error、权限不足状态完整。
- 桌面与移动截图检查通过。
